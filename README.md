# 文件相关内容

* 网页素材：网页相关文件，例如图片的备份；
* audio：存储音乐的位置，未来在文件夹中进行细化分类，如按歌手分类；
* images
  * books：图书的图片；

  * log：日志图片；

  * web：网页图片。

* json：
  * download.json：
    * 更新配置信息
  * duty_date.json：
    * 值日表
  * log_inside：
    * 日志内作者配置信息
  * log_web：
    * 网页日志配置信息
  * log.json：
    * 软件日志配置信息
* svgs：
  * 软件使用的svg图片
